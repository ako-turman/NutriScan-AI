# Зертханалық жұмыс №3

## Бағдарламалық қамсыздандырудың өмірлік циклдерінің модельдері

**Жоба:** NutriScan AI: Personal Diet & Product Assistant

---

## Жұмыстың мақсаты

Бағдарламалық қамсыздандырудың өмірлік циклінің негізгі модельдерін зерттеу, олардың құрылымы мен ерекшеліктерін қарастыру және NutriScan AI жобасының әзірлеу процесіне бейімдеп модельдеу.

---

## 1. Алгоритмдердің блок-сұлбалары

### 1.1 Күнделікті калория нормасын есептеу алгоритмі

Алгоритм пайдаланушының салмағы, бойы, жасы, жынысы, белсенділік деңгейі және мақсаты туралы мәліметтер негізінде күнделікті калория нормасын есептеуді көрсетеді.

```mermaid
flowchart TD
    Start([Бастау]) --> InputParams[/Деректерді енгізу: Салмақ, Бой, Жас, Жыныс, Мақсат, Тамақтану_Саны/]
    InputParams --> CalcBMR["BMR = 10*Салмақ + 6.25*Бой - 5*Жас + Коэффициент"]
    CalcBMR --> CalcNorma["Норма = BMR * Белсенділік<br>Sum_Cal = 0<br>i = 1"]
    CalcNorma --> LoopCheck{i <= Тамақтану_Саны?}
    LoopCheck -- Иә --> InputMeal[/i-ші тамақтану калориясын енгізу: Meal_Cal/]
    InputMeal --> AddCal["Sum_Cal = Sum_Cal + Meal_Cal<br>i = i + 1"]
    AddCal --> LoopCheck
    LoopCheck -- Жоқ --> PrintResult[/Экранға шығару: Sum_Cal және Норма/]
    PrintResult --> End([Соңы])
```

### 1.2 Өнім құрамындағы аллергендерді анықтау алгоритмі

Алгоритм өнім ингредиенттерін пайдаланушы көрсеткен аллергендер тізімімен салыстырып, қауіпті ингредиенттерді анықтау процесін көрсетеді.

```mermaid
flowchart TD
    Start([Бастау]) --> InputData[/Енгізу: Штрих-код немесе өнім фотосы, Аллергендер тізімі A/]
    InputData --> InitVars["Ингредиенттер массивін алу T(1..M)<br>K = 0<br>i = 1"]
    InitVars --> LoopCheck{i <= M?}
    LoopCheck -- Иә --> ConditionCheck{"T(i) ингредиенті A тізімінде бар ма?"}
    ConditionCheck -- Иә --> Found["T(i) қауіпті деп белгілеу<br>K = K + 1"]
    Found --> NextIndex["i = i + 1"]
    ConditionCheck -- Жоқ --> NextIndex
    NextIndex --> LoopCheck
    LoopCheck -- Жоқ --> PrintResult[/Экранға нәтижені шығару: K табылған аллергендер/]
    PrintResult --> End([Соңы])
```

## 2. Бағдарламалық қамсыздандырудың өмірлік цикл модельдері

### 2.1 Каскадты модель (Waterfall Model)

Каскадты модельде бағдарламалық өнімді әзірлеу кезеңдері бірінен кейін бірі ретімен орындалады.

```mermaid
flowchart TD
    A["1. Талаптарды талдау<br>(NutriScan AI функцияларын бекіту)"] --> B["2. Жүйелік жобалау<br>(Дерекқор және сәулет)"]
    B --> C["3. Бағдарламалау / Кодтау<br>(Kotlin / API / OpenAI)"]
    C --> D["4. Жүйелік тестілеу<br>(КБЖУ мен AI дәлдігін тексеру)"]
    D --> E["5. Пайдалануға енгізу<br>(Google Play / Қолдау)"]
```

### 2.2 Кері байланысы бар каскадты модель

Бұл модель қате анықталған жағдайда алдыңғы жобалау немесе әзірлеу кезеңіне қайта оралуға мүмкіндік береді.

```mermaid
flowchart TD
    A["1. Талаптарды талдау"] --> B["2. Жүйелік жобалау"]
    B --> C["3. Кодтау және әзірлеу"]
    C --> D["4. Тестілеу фазасы"]
    D -- "Қате табылса" --> B
    D -- "Қате табылса" --> C
    D -- "Тесттен сәтті өтсе" --> E["5. Енгізу және қолдау"]
```

### 2.3 V-тәрізді модель (V-Model)

V-Model әзірлеудің негізгі кезеңдерін оларға сәйкес тестілеу кезеңдерімен байланыстырады.

```mermaid
flowchart TD
    subgraph Әзірлеу_фазасы
        V1["Талаптарды талдау"]
        V2["Жүйелік жобалау"]
        V3["Модульдік жобалау"]
        V4["Кодтау (Implementation)"]
    end

    subgraph Тестілеу_фазасы
        T3["Юнит тестілеу (Unit Test)"]
        T2["Интеграциялық тест"]
        T1["Қабылдау тесті (Acceptance)"]
    end

    V1 --- T1
    V2 --- T2
    V3 --- T3
    V4 --> T3
    T3 --> T2
    T2 --> T1
```

### 2.4 RAD — Rapid Application Development

RAD прототиптерді жылдам әзірлеуге және кері байланыс негізінде жүйені жетілдіруге бағытталған.

```mermaid
flowchart LR
    R1["1. Талаптарды жоспарлау"] --> R2["2. Пайдаланушы дизайны<br>(Прототиптеу)"]
    R2 --> R3["3. Жылдам құрастыру<br>(Кодтау)"]
    R3 -- "Кері байланыс / Түзету" --> R2
    R3 --> R4["4. Енгізу және жүктеу"]
```

### 2.5 Шиыршықты модель (Spiral Model)

NutriScan AI жобасы бірнеше айналым арқылы кезең-кезеңімен дамытылады.

```mermaid
flowchart TD
    S1["1-ші айналым: MVP Калькулятор<br>(Тәуекел: Төмен)"] --> S2["2-ші айналым: Штрих-код сканері<br>(Тәуекел: Дерекқор тапшылығы)"]
    S2 --> S3["3-ші айналым: AI Фото Талдау<br>(Тәуекел: API шығыны мен дәлдік)"]
    S3 --> S4["4-ші айналым: Толық NutriScan AI релизі"]
```

### 2.6 Тәуекел деңгейінің әзірлеу уақытына тәуелділігі

Жоба дамыған сайын белгісіздік азайып, тәуекел деңгейінің төмендеуі көрсетілді.

```mermaid
xychart-beta
    title "NutriScan AI: Тәуекел деңгейінің уақытқа тәуелділігі"
    x-axis ["Талаптарды талдау", "Жобалау", "MVP", "Сканер/API", "Толық релиз"]
    y-axis "Тәуекел деңгейі (%)" 0 --> 100
    line [90, 75, 50, 30, 10]
    bar [90, 75, 50, 30, 10]
```

### 2.7 Экстремалды бағдарламалау (Extreme Programming, XP)

XP қысқа әзірлеу циклдеріне, тестілеуге және пайдаланушының тұрақты кері байланысына негізделеді.

```mermaid
flowchart TD
    X1["Пайдаланушы сценарийлері (User Stories)"] --> X2["TDD: Алдымен тест жазу"]
    X2 --> X3["Жұптық программалау (Pair Programming)"]
    X3 --> X4["Шағын релиз (Small Release)"]
    X4 -- "Пайдаланушы пікірі" --> X1
```

## Қорытынды

Зертханалық жұмыс барысында бағдарламалық қамсыздандырудың өмірлік циклінің негізгі модельдері қарастырылып, NutriScan AI жобасының мысалында бейімделді.

Waterfall, кері байланысы бар Waterfall, V-Model, RAD, Spiral және Extreme Programming модельдерінің құрылымдары диаграммалар арқылы көрсетілді. Сонымен қатар NutriScan AI жүйесіне қатысты алгоритмдердің блок-сұлбалары және жобаны әзірлеу кезіндегі тәуекел деңгейінің өзгеру графигі құрылды.

Нәтижесінде бағдарламалық өнімді әртүрлі тәсілдермен әзірлеу кезеңдері мен модельдердің негізгі ерекшеліктері қарастырылды.
